# 🤖 Hyper-AI Автономный Торговый Telegram-бот

Этот проект представляет собой ультимативного торгового ИИ-ассистента и автономного бота, управляемого через Telegram. Бот работает с криптобиржами (Binance, Bybit, OKX и др. через `ccxt`) и акциями (Tinkoff).

Главная особенность — **сверх-глубокий мульти-векторный анализ**, который синтезирует данные из технического, фундаментального, макроэкономического и on-chain анализа через **Ролевой ИИ-Консилиум**.

> 📖 **ПОЛНОЕ РУКОВОДСТВО**: Пожалуйста, обратитесь к файлу [GUIDE.md](GUIDE.md) для получения подробнейших инструкций по настройке, добавлению LLM-ключей (Groq, DeepSeek, OpenAI) и использованию всех умных функций бота (Paper Trading, Smart Alerts, DCA, Watchlist).

## 🌟 Ультимативные возможности аналитики

Бот не просто смотрит на график. Перед сделкой он анализирует:
*   **Технический анализ**: RSI, MACD, Bollinger Bands, поиск точек разворота.
*   **Анализ Стакана и Деривативов**: Сканирование "Стен ордеров" (Bid/Ask Walls) и Ставок финансирования (Funding Rates) для предсказания сквизов.
*   **On-Chain киты**: Отслеживание аномальных переводов крипты в блокчейне (Whale Tracker).
*   **Макроэкономика и Фон**: Индекс страха и жадности, экономический календарь (ФРС, инфляция CPI).
*   **Социальный Сентимент**: Парсинг новостей, Reddit, Telegram-каналов на предмет хайпа вокруг монеты.

Все эти потоки данных передаются в **Консилиум ИИ**, где несколько LLM (GPT-3.5, DeepSeek, Groq, Claude) с ролями "Фундаменталист", "Техник" и "Риск-Менеджер" голосуют за принятие решения.

## 💼 Режимы торговли

1.  **Полный Автопилот**: Бот торгует сам, используя выбранную стратегию (Тренд, Сетка, DCA) и учитывая глобальный фон.
2.  **Режим ИИ-Советника (Advisory)**: Бот присылает вам **Смарт-Алерт** с подробным отчетом по монете и двумя кнопками: `[✅ Подтвердить]` или `[❌ Отклонить]`.
3.  **Виртуальный счет (Paper Trading)**: Торговля на фантики (с возможностью пополнения счета через бота) с реальными графиками, чтобы безопасно тестировать стратегии. Бот честно считает ваш **PnL**.
4.  **Калькулятор усреднения (DCA)**: Если вы в просадке >10%, бот сам предложит докупить актив, чтобы снизить цену безубытка.
5.  **Копитрейдинг и Watchlist**: Бот сканирует только те монеты, которые вам интересны, либо автоматически ищет монеты с максимальным объемом торгов.

## 🛠 Установка и запуск (Через Docker)

### 1. Подготовка
Убедитесь, что у вас установлены:
*   [Docker](https://docs.docker.com/get-docker/)
*   [Docker Compose](https://docs.docker.com/compose/install/)

### 2. Получение токена Telegram-бота
1. Откройте Telegram и найдите бота [@BotFather](https://t.me/botfather).
2. Напишите команду `/newbot`, задайте имя.
3. Скопируйте полученный **API Token**.

### 3. Настройка окружения
Создайте в корне проекта файл `.env` и добавьте в него ваш токен:

```env
TELEGRAM_TOKEN=123456789:AAH_ваша_строка_токена_здесь
```

### 4. Запуск
Откройте терминал в папке с проектом и выполните команду:

```bash
docker-compose up --build -d
```
Бот и база данных PostgreSQL будут запущены автоматически в фоне.

## 📱 Быстрый старт

После запуска перейдите в бота в Telegram и отправьте `/start`.
Для настройки API-ключей, изменения режимов торговли (Реальный/Виртуальный счет, Авто/Советник) и настройки ИИ Консилиума используйте встроенные inline-кнопки в меню **⚙️ Настройки**.

Подробное описание всех команд и логики анализа находится в [GUIDE.md](GUIDE.md).
