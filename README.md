# 🤖 Автономный торговый Telegram-бот с ИИ Консилиумом

Этот проект представляет собой полностью автономного торгового бота, управляемого через Telegram. Бот поддерживает работу с криптовалютными биржами (через `ccxt`) и Тинькофф Инвестициями. Главная особенность — интеграция с большими языковыми моделями (LLM) в виде "Консилиума ИИ", который анализирует мировые новости и фундаментальный фон для принятия безопасных торговых решений.

## 🌟 Основные возможности

*   **Мульти-биржевость:** Binance, Bybit, OKX, Tinkoff и другие (через интерфейс `ccxt`).
*   **Торговые стратегии:**
    *   *Auto* (автоматический выбор на основе ADX/тренда)
    *   *Grid* (сеточная торговля для флэта)
    *   *Trend* (торговля по тренду на основе скользящих средних)
    *   *DCA* (усреднение долларовой стоимости)
*   **ИИ Консилиум:** Сбор новостей по RSS и анализ тональности с помощью базового NLP (VADER) или нескольких LLM (OpenAI, DeepSeek, Anthropic и др.). Бот не будет покупать активы, если ИИ определит мировую панику.
*   **Управление через Telegram:** Удобное меню для просмотра портфеля, добавления ключей, настройки рисков и получения аналитики.

## 🛠 Установка и запуск

Проект полностью упакован в Docker для простоты развертывания. База данных (PostgreSQL) разворачивается автоматически вместе с ботом.

### 1. Подготовка
Убедитесь, что у вас установлены:
*   [Docker](https://docs.docker.com/get-docker/)
*   [Docker Compose](https://docs.docker.com/compose/install/)

### 2. Получение токена Telegram-бота
1. Откройте Telegram и найдите бота [@BotFather](https://t.me/botfather).
2. Напишите команду `/newbot`, задайте имя и username.
3. Скопируйте полученный **API Token**.

### 3. Настройка окружения
Создайте в корне проекта файл `.env` и добавьте в него ваш токен:

```env
TELEGRAM_TOKEN=123456789:AAH_ваша_строка_токена_здесь
```

### 4. Запуск
Откройте терминал в папке с проектом и выполните команду:

```bash
docker-compose up --build -d
```
Эта команда скачает нужные образы, соберет бота, запустит базу данных PostgreSQL и самого торгового движка в фоновом режиме.

## 📱 Как пользоваться ботом

Перейдите в вашего созданного бота в Telegram и отправьте команду `/start`.

### 1. Настройка ключей (⚙️ Настройки)
*   Нажмите **⚙️ Настройки** -> **🔑 API ключи Бирж**.
*   Выберите биржу (например, Binance или Tinkoff).
*   Бот пошагово запросит у вас API Key и API Secret (для Tinkoff нужен только токен). Ключи безопасно сохранятся в вашу базу данных.

### 2. Настройка ИИ и Консилиума (🧠 Настройки ИИ)
*   В настройках перейдите в **🧠 Настройки ИИ (LLM)**.
*   Нажмите **🔑 Добавить ключ LLM**, введите название провайдера (например, `openai`) и ваш API-ключ от этого сервиса.
*   Нажмите **🟢 Включить Консилиум**. Теперь бот будет опрашивать LLM перед каждой сделкой.

### 3. Выбор стратегии и рисков
*   В настройках выберите **🛠 Стратегия и Риски**.
*   Выберите стратегию (рекомендуется **Автоматическая**).
*   Введите максимальный риск на сделку в процентах (например, `1` означает, что бот будет использовать 1% от баланса для одного ордера).

### 4. Запуск торгов
*   Нажмите **🚀 Запустить торговлю**.
*   Фоновый движок начнет работу. Раз в минуту он будет анализировать рынок, собирать мировые новости (и опрашивать ИИ), и при совпадении условий автоматически открывать/закрывать сделки. Вы будете получать уведомления в Telegram о каждом действии.

### 5. Аналитика и контроль
*   **📊 Портфель:** Показывает текущие балансы на всех подключенных биржах.
*   **🌍 Анализ рынка и мира:** Бот вручную собирает свежие новости, отправляет их на консилиум ИИ и выдает вам подробный отчет о том, что сейчас происходит в мире (Позитив/Негатив/Нейтрально) и почему.
*   **📈 История сделок:** Показывает 10 последних совершенных ботом операций.
*   **🛑 Остановить торговлю:** Принудительно запрещает боту открывать новые сделки.

## 🛑 Остановка и удаление

Чтобы остановить бота, находясь в папке с проектом, выполните:
```bash
docker-compose down
```
*(Ваши ключи и история сделок сохранятся в Docker volume `postgres_data`, так что при следующем запуске ничего не пропадет).*
